What stays the same on every rail

Switching the settlement rail does not change the guarantee. The part that matters is rail-neutral by design.

Non-custodial

Funds settle straight to the payee. BSVKey never holds them, on any rail.

Pay per call

Metered settlement per request, no accounts or prepaid lock-in required.

Verifiable receipts

A content-addressed, signed record of each settled call that anyone can verify offline, tied to the on-chain transaction. The claim format is shared across rails; only the signature envelope and address encoding are rail-specific.

We build the verifiable-receipt layer in the open. We contributed the BSV rail to an emerging post-call attestation standard for agent payments: EmbryoSpace/bsv-capacity-attest. The XRP rail follows the same content-addressed core and is open-source too: EmbryoSpace/xrp-capacity-attest.
